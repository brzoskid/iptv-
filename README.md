# webOS IPTV Player dla Minix NEO-U1 (v4)

- Domyślnie skonfigurowany adres listy IPTV: `https://hls.gd/pl/81/8fehsacnmhby7/playlist.m3u8` (w ustawieniach `≡ Menu` z możliwością zmiany na dowolny inny adres URL lub wgrania plików `.m3u`).
- Wbudowane 3 źródła EPG (`epg.ovh/pl.xml`, `pltv.xml`, `plar.xml`) z przełącznikiem **WŁĄCZ / WYŁĄCZ**.
- Pełna obsługa pilota **MINIX NEO A2 Lite / A3** oraz klawiatury USB.
- Silnik wideo **ExoPlayer 2.13.3** (Android 5.1.1 API 22).
